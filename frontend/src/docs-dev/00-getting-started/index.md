title: Getting Started
---

Technical reference for developers working on the Morphy codebase.

Morphy is a self-hosted AI agent platform that runs on a user's machine, providing an autonomous AI agent (backed by Claude, Codex, or Pi) with a chat interface, workspace modification capabilities, a stable public URL through the built-in Morphy carrier (a persistent outbound connection to Cloudflare's edge), and a monitoring dashboard.
